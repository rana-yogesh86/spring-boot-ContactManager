About

A simple, focused way to manage your contacts

Contact Manager is a lightweight Spring Boot application for storing, searching, and organizing the people you work with — no clutter, no unnecessary steps, just fast add/edit/find.

What it does

Store contacts

Save names, phone numbers, emails, and notes in one organized place.

Search instantly

Find any contact in seconds by name, phone, or email.

Edit anytime

Update contact details as things change, with changes saved immediately.

Remove clutter

Delete outdated or duplicate entries in one click.

Built with

Java Spring Boot Spring Data JPA Thymeleaf MySQL
